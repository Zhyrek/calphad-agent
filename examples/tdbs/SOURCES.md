# Example databases: sources

These TDB files are published or distributed CALPHAD assessments, kept here as examples and test inputs for the toolkit. They are unchanged, and each file's own header comment names its authors.

Please cite the original work when you use them. The copyright and terms of use of each source still apply, and this repository's MIT licence does **not** cover these files.
